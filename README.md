# Testes SQL 🗄️

Repositório pessoal dedicado a estudos, testes práticos e anotações de scripts SQL com MySQL.

---

## 📁 Estrutura de Pastas

```text
testes-sql/
├── testes/
│   └── loja_vendas.sql    # Exemplo prático de DDL e DML (CREATE, INSERT, SELECT, UPDATE)
├── .gitignore             # Proteção contra envio de dados sensíveis e temporários
└── README.md              # Documentação do repositório
```

---

## 🚀 Scripts Disponíveis

* **`testes/loja_vendas.sql`**: Roteiro completo de um fluxo de vendas, abordando:
  * Criação de banco de dados e tabelas relacionais (`PRIMARY KEY` e `FOREIGN KEY`).
  * Inserção de registros com múltiplos valores (`INSERT INTO`).
  * Consultas filtradas e ordenadas (`SELECT`, `WHERE`, `ORDER BY`).
  * Atualização de registros e controle de estoque (`UPDATE`).
